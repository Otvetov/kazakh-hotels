# Kazakh Hotels

Веб-приложение для поиска и бронирования отелей по Казахстану. Разработано на Laravel 12.

## Технологический стек

- Backend: Laravel 12, PHP 8.3+
- База данных: MySQL 8.4
- Frontend: Blade, Tailwind CSS 4, Vite, нативный JavaScript
- Аутентификация: сессии (веб-интерфейс) и токены Laravel Sanctum (API)
- Локализация: русский, английский, казахский языки

## Возможности

### Публичная часть

- Поиск отелей по городу, датам заезда и выезда, числу гостей и номеров.
- Каталог отелей с фильтрами по цене за ночь и рейтингу, сортировкой по популярности, цене и рейтингу, постраничной навигацией.
- Страница отеля: фотогалерея с просмотром в полноэкранном режиме, описание, список номеров с ценами, вместимостью и фотографиями, отзывы гостей.
- Отзывы с оценкой и модерацией администратором (отправка без перезагрузки страницы).
- Переключение языка интерфейса (RU/EN/KK) и тёмной/светлой темы.
- Встроенный чат-помощник (опционально, см. раздел «Чат-помощник»).

### Для авторизованных пользователей

- Бронирование номера на выбранные даты с проверкой доступности.
- Страница оплаты бронирования (демонстрационная) и подтверждение.
- Список бронирований: активные, прошедшие, отменённые; отмена брони.
- Избранные отели (добавление и удаление без перезагрузки страницы).
- Профиль с историей бронирований и редактированием данных (имя, email, смена пароля).

### Административная панель

- Сводная статистика: бронирования, доход, отели, пользователи, ожидающие отзывы и подтверждения.
- Управление отелями (создание, редактирование, удаление) и галереей фотографий.
- Управление номерами.
- Управление пользователями: блокировка и разблокировка.
- Управление бронированиями: смена статуса.
- Модерация отзывов: одобрение и отклонение.

### API

REST API под префиксом `/api/v1` с аутентификацией через токены Sanctum.

- Публичные эндпоинты: регистрация, вход, список и просмотр отелей.
- Защищённые эндпоинты (`auth:sanctum`): данные пользователя, бронирования, избранное, отзывы, выход.

Описание доступно на странице `/api-docs`.

## Установка

1. Клонировать репозиторий и перейти в каталог проекта:

   ```bash
   git clone https://github.com/Otvetov/kazakh-hotels.git
   cd kazakh-hotels
   ```

2. Установить зависимости:

   ```bash
   composer install
   npm install
   ```

3. Подготовить файл окружения и сгенерировать ключ приложения:

   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

4. Указать параметры подключения к базе данных в `.env`:

   ```env
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=kazakh_hotel
   DB_USERNAME=root
   DB_PASSWORD=
   ```

5. Выполнить миграции и создать символическую ссылку на хранилище:

   ```bash
   php artisan migrate
   php artisan storage:link
   ```

6. Заполнить базу тестовыми данными:

   ```bash
   php artisan db:seed
   ```

   Будет создано:

   - администратор `admin@example.com` с паролем `password`;
   - 10 тестовых пользователей;
   - 49 реальных отелей в 20 городах Казахстана с номерами, бронированиями, избранным и отзывами.

   Фотографии отелей и номеров подгружаются с внешнего бесплатного фотобанка (Pexels), поэтому для их отображения нужен доступ в интернет.

7. Собрать ресурсы фронтенда:

   ```bash
   npm run build
   ```

8. Запустить сервер разработки:

   ```bash
   php artisan serve
   ```

   Для пересборки ресурсов в режиме разработки используется `npm run dev`.

Приложение будет доступно по адресу `http://127.0.0.1:8000`.

## Учётная запись администратора

После заполнения базы данных:

- Email: `admin@example.com`
- Пароль: `password`

## Чат-помощник

В приложение встроен чат-помощник, отвечающий на вопросы об отелях и бронировании. Он использует Anthropic Claude API и подключается через переменные окружения:

```env
ANTHROPIC_API_KEY=
ANTHROPIC_MODEL=claude-opus-4-8
```

Ключ указывается пользователем самостоятельно. Если ключ не задан, помощник возвращает базовые подсказки по сайту и остаётся работоспособным. После изменения `.env` нужно выполнить `php artisan config:clear`.

## Структура базы данных

- `users` — пользователи, роли, статус блокировки.
- `hotels` — отели.
- `hotel_images` — фотографии галереи отелей.
- `rooms` — номера отелей.
- `bookings` — бронирования.
- `favorites` — избранные отели.
- `reviews` — отзывы со статусами: ожидает, одобрен, отклонён.
- `personal_access_tokens` — токены доступа Sanctum для API.

## Развёртывание

1. Установить `APP_ENV=production` и `APP_DEBUG=false` в `.env`.
2. Закешировать конфигурацию и маршруты:

   ```bash
   php artisan config:cache
   php artisan route:cache
   php artisan view:cache
   ```

3. Собрать ресурсы фронтенда: `npm run build`.
4. Убедиться в наличии символической ссылки на хранилище: `php artisan storage:link`.
